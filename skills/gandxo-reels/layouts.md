## 9. Carrousels, stories, légendes

**Carrousel 1080×1350, 10–12 slides** : 1) cover qui stoppe le scroll (pastille rouge, titre blanc à double ombre, mot rouge, barre de recherche + badge) ; 2) slides d'élément : pastille `NN · CATÉGORIE`, nom en rouge géant (≤ 640 px), illustration, barre avec l'URL + badge, carte avec puces ≤ 42 caractères, panneau « À SAVOIR » ; 3) slide finale : ENREGISTRE CE POST, barre avec `PROJET` + badge DM, chip « ABONNE-TOI À @EXAUCE_OBAGUIDI ».

**Stories** : teaser « CE / SOIR » (rouge géant à ombre bleue, interligne 0,87 × taille) et annonce « C'EST POSTÉ », même sous-titre, barre `commente PROJET` + badge DM, pastille @. Version animée : barre 0,05→1,20 s, titre qui tombe 0,10→0,66 s (dy −900, rotation −7°, easeOutBack) puis tremblement, sticker 0,70 s, pastille 0,72 s, accroche 1,05 s, barre 1,35 s → 2,20 s, maintien jusqu'à 4 s. Le titre reste **un seul calque**, sinon l'ordre de lecture casse.

**Légende** : gabarit exact dans `gandxo-idee-au-produit` §7. Ligne 1 ≤ 125 caractères avec le hook ; 3–5 hashtags précis dont `#benin` ; un seul CTA (`PROJET`) ; une seule question. Bloc copiable, ≤ 2 200 caractères.
